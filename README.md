# Tableau de bord Contrôle Interne — Groupe ERANOVE

Application web de suivi des indicateurs de contrôle interne.
12 filiales déclarantes, 7 indicateurs, remontée mensuelle, consolidation temps réel.

> **Données fictives uniquement.**
> Aucune donnée réelle du groupe ERANOVE ne figure dans ce dépôt ni dans
> l'environnement de démonstration. Le jeu de données est généré par une fonction
> de hachage déterministe.

## Démarrage

```bash
npm install
cp .env.example .env     # puis renseigner les valeurs
npm run dev
```
